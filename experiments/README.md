# Assignment 5 experiment ledger

All runs should record: git commit, command, config, seed, GPU assignment, checkpoint path, log path, and evaluation result.
The public repository does not include Stanford's copyrighted MATH-12K data. Per the assignment handout's open-source auditor note, this server uses the bundled GSM8K data for reproducible SFT/EI/GRPO experiments unless a MATH path is supplied explicitly.
